HandshakeOS for the Anbernic RG35XX 2024 — flash instructions
=========================================================
Built 2026-11-19, 5:51 PM America/New_York.

This image is for a SECOND microSD card (TF1). Do not overwrite the
stock card. Back that card up first (see board/rg35xx-2024/windows-backup-stock-sd.ps1
in the HandshakeOS repo).

Play wins ties: the machine that already plays games stays on the
stock card until you are happy with this one.

Decompress (PowerShell, in this folder)
---------------------------------------
  # Verify the compressed copy first
  Get-FileHash .\handshakeos-rg35xx-2024.img.zst -Algorithm SHA256
  # Then decompress with one of:
  zstd -d -f .\handshakeos-rg35xx-2024.img.zst
  # or PeaZip / 7-Zip (zstd). After that:
  Get-FileHash .\handshakeos-rg35xx-2024.img -Algorithm SHA256
The raw hash must match c12d12e1bff25515e1af8e440dd37f91954fc9febdddc3fb1b1e135fd6826352.

Flash
-----
1. Open Rufus, Raspberry Pi Imager, or balenaEtcher.
2. Select handshakeos-rg35xx-2024.img (the raw file, not the .zst).
3. Select the SECOND microSD card. Triple-check the drive letter.
4. Write the image. Eject the card safely.
5. Plug the card into the RG35XX 2024 (the TF1 slot reserved for experiments).
6. Boot. You should get:
     - serial (UART, 115200 8N1, earlycon 0x05000000): "HandshakeOS PID 1" + handshake ledger
     - 640x480 Deep Purple shell on the panel (first light-up is the hardware test)

Image layout (MBR, 248 MiB)
---------------------------
  0..8 MiB     gap; LPDDR3 u-boot-sunxi-with-spl at 8 KiB (eGON.BT0 at 0x2004)
  p1 64 MiB    FAT32  HS_BOOT  (bootable)  Image, NV3052C DTB, extlinux.conf, boot.scr
  p2 80 MiB    ext4   HS_ROOT  static /init (handshake-init), /bin/handshake-gb, /roms
  p3 96 MiB    FAT32  HS_ROMS  legal .gb files, visible from Windows

Kernel / boot chain
-------------------
  Linux 7.3.5 aarch64, TF-A lts-v2.14.14 (PLAT=sun50i_h616),
  U-Boot v2026.10 anbernic_rg35xx_h700_lpddr3_defconfig
  (LPDDR3, 1024 MiB, DCDC3 1.2 V, 672 MHz). LPDDR4 is the alternate revision.
  DTB: sun50i-h700-anbernic-rg35xx-2024.dtb (NV3052C-clean).
  cmdline: console=ttyS0,115200 earlycon=uart8250,mmio32,0x05000000
           root=LABEL=HS_ROOT rootwait rw init=/init handshakeos.serial

After flashing, Windows will see two FAT32 partitions if you plug the
card into a PC: HS_BOOT and HS_ROMS. The ext4 HS_ROOT partition
Windows will ignore; that is expected.

HS_ROMS ships handshake-demo.gb (MIT, original) and libbet.gb (zlib,
Libbet and the Magic Floor v0.08, Damian Yerrick). You can add more
open-source / public-domain .gb files from Explorer. Commercial ROMs
are not included and should not be added unless you own the rights.

If the panel is garbage or stays black, this unit may be a Rev 6 / YLM
panel variant. Keep the stock card safe; a second DTB would be a
hardware-only follow-up. Buttons, backlight, the second SD slot, and
on-device audio likewise need a real-hardware pass to sign off.

The stock firmware does not enumerate the handheld over USB, so this
image has to be written in a card reader — it cannot be flashed from
the box remotely.
